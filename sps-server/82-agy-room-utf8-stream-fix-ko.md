# Agy Room UTF-8 스트림 수정

작성일: 2026-07-13

## 증상

Room 또는 Worker Task의 한글 답변과 첨부 파일명이 깨져 보이거나 `U+FFFD` 대체 문자로 저장될 수 있었다.

## 원인

UTF-8 한글 문자는 여러 바이트로 구성된다. SPS의 외부 Agy 어댑터가 표준 출력의 각 조각을 독립적으로 문자열로 변환하면, 한 글자의 바이트가 두 조각으로 나뉠 때 잘못된 문자열이 만들어진다. 이미 `U+FFFD`로 변환된 과거 데이터는 원본 바이트가 없어 복원할 수 없다.

## 적용한 방어

1. `AgyRoomClient`는 출력 조각을 Buffer로 보관한 뒤 strict UTF-8로 한 번에 해석한다.
2. Room 플러그인은 회복 가능한 라틴1 모지바케를 표시와 저장 경계에서 보정한다.
3. `U+FFFD`가 있는 Room 입력 또는 Agent 출력은 저장하지 않고 명시적인 오류로 종료한다.
4. `Apply-SPSUtf8StreamCompatibility.ps1`은 SPS 외부 Agy 어댑터의 스트림 디코딩을 strict UTF-8 스트리밍 방식으로 보정한다.
5. 호환 스크립트는 정확한 upstream 코드 형태를 확인한 경우에만 적용한다. SPS 업데이트로 구조가 달라지면 임의로 수정하지 않고 `not_applicable` 상태를 반환한다.

## 운영

- SPS 시작 스크립트가 호환 패치를 매번 확인한다.
- `Test-SPSUtf8StreamCompatibility.mjs`는 한글 바이트를 글자 중간에서 나누어도 보존되는지와 잘못된 바이트를 거부하는지를 검사한다.
- 새 메시지는 UTF-8로 보존된다. 과거에 이미 `U+FFFD`로 저장된 본문은 원본 파일이나 원래 메시지에서 다시 가져와야 한다.
