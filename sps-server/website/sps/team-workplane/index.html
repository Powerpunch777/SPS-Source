WHAT IT ADDS

대화와 실행을 혼동하지 않는 팀 작업면

Team Room은 역할별 장기 맥락을 유지하고, Task Room은 하나의 목표가 끝날 때 닫히는 실행 공간입니다. Lead만 Worker에게 Task를 할당하며, 완료나 작업 불가 결과는 만든 Lead의 Room으로 보고됩니다.

01

Team Room

프로젝트 안에서 Agent별 장기 대화, 지침, 작업 맥락을 보존합니다.

02

Task Room

목표, 담당자, 수락 기준을 가진 한정된 작업 대화를 만들고 결과를 남깁니다.

03

Durable Memory

Room 기록, 압축 요약, 첨부 참고, 작업 상태를 재시작 뒤에도 복원합니다.

PERMISSION PREVIEW

설치 전에 보이는 권한, 활성화 뒤에만 실행되는 기능

Registry는 package hash와 권한 목록을 먼저 검증합니다. 이 플러그인은 UI 등록, 프로젝트와 Task 읽기·쓰기, Agent 세션 호출, Room 메모리, 예약 작업을 사용합니다. 로컬 CLI나 컴퓨터 제어 권한은 이 플러그인이 직접 받지 않으며, 실제 실행은 Core의 승인된 Node와 Agent runner grant를 계속 통과해야 합니다.

  • UITeam Room, Task, 프로젝트 보기를 등록합니다.
  • 작업 데이터Issue, 댓글, 문서, 프로젝트 작업공간을 읽고 필요한 Task 기록을 씁니다.
  • Agent 세션승인된 Agent의 세션을 만들고 Task 흐름 안에서 메시지를 보냅니다.
  • 복구 작업누락된 Worker 보고와 Room 상태를 재조정하는 예약 작업을 등록합니다.

INSTALL BOUNDARY

발견, 검증, stage, Owner 활성화 순서로만 설치합니다.

SPS Desktop에서 SPS Official Registry를 추가한 뒤 release 0.3.82를 stage합니다. package와 서명이 확인되면 disabled 상태로 review queue에 들어가며, Owner가 권한을 검토하고 적용할 때만 plugin lifecycle이 시작됩니다.
