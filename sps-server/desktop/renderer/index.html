SPS DESKTOP

어디에서 시작할까요?

SPS Server가 회사, Workspace, 플러그인 데이터와 컴퓨터 연결을 보관합니다. SPS 계정은 그 서버에 접근할 사람을 구분합니다.

초대 수락과 서버 접근 확인은 브라우저에서 이어집니다.

THIS COMPUTER'S SPS SERVER

SPS Server 관리

이 컴퓨터가 회사 데이터와 팀 접근 권한을 관리합니다.

활성화하면 Tailscale 네트워크에 있는 초대된 팀원이 이 SPS Server에 안전하게 참여할 수 있습니다.

전체 SPS2-... 코드를 그대로 전달하세요. 새 컴퓨터에는 짧은 SPS 코드만으로 서버 주소를 알 수 없습니다.

Provider runtimes are optional. Download and extract a release pack, then choose its folder. SPS never downloads one implicitly.

OWNER HOST

Host project folders

Only the Owner Host chooses a project's source folder. Member computers receive an SPS-managed shared path only while they are approved to run that project's Task.

These folders remain on this Host. SPS never asks a Member to choose or replace a project's source folder.
