# First Unreal QA baseline inspection

## Goal

Perform a read-only QA baseline inspection of the currently selected local Unreal project. Establish what can be tested now, what is missing for repeatable QA, and the highest-value next checks for a small two-person game team.

## Authorized scope

- Inspect project structure, configuration, existing source/assets metadata, tests, and existing documentation only.
- Do not edit gameplay code, Blueprints, assets, project settings, or documentation.
- Do not build, package, launch Unreal Editor, run a game executable, or run destructive commands.
- Do not create additional SPS issues. The current Task Room is the only report destination.

## Report requirements

In the Task Room close summary, include:

1. Test scope and inspection basis.
2. Existing testability signals and QA gaps.
3. Concrete reproducible checks a developer can perform next, with expected versus actual observations where inspection permits.
4. Severity/risk ordered findings, clearly distinguishing verified facts from inference.
5. One recommended next action that is small enough to become a separate Task Room.

## Memory

Propose a memory candidate only if a durable process rule is discovered. Do not promote or write to approved memory.
